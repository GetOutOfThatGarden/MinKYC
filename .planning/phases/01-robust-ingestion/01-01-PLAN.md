  <name>A2: Implement NFC Config Plugin</name>
  <files>mobile/App/plugins/withNFC.js, mobile/App/app.json</files>
  <action>
    Create a custom Expo Config Plugin `withNFC.js` that:
    1. Adds `android.permission.NFC` and `<uses-feature android:name="android.hardware.nfc" />` to AndroidManifest.xml.
    2. Configures iOS `com.apple.developer.nfc.readersession.iso7816.select-identifiers` with the ICAO AID: `A0000002471001`.
    3. Adds `NFCReaderUsageDescription` to Info.plist.
    Register the plugin in `app.json` or `app.config.ts`.
  </action>
  <verify>
    <automated>cd mobile/App && npx expo prebuild --platform android --dry-run</automated>
  </verify>
  <done>Config plugin created and registered; prebuild confirms manifest injections.</done>
</task>
